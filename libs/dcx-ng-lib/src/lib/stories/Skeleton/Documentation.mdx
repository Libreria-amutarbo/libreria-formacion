# Skeleton

`dcx-ng-skeleton` muestra un placeholder decorativo mientras el contenido real está cargando.
Está inspirado en PrimeNG Skeleton y mantiene una API simple para formas, medidas y animación.

## Available Properties

- **shape**: `'rectangle' | 'circle'` - Forma visual del placeholder (default: `'rectangle'`).
- **width**: `string` - Ancho CSS cuando no se usa `size` (default: `'100%'`).
- **height**: `string` - Alto CSS cuando no se usa `size` (default: `'1rem'`).
- **size**: `string | null` - Tamaño único para ancho y alto (default: `null`).
- **borderRadius**: `string | null` - Radio CSS para rectángulos (default: `null`).
- **animation**: `'wave' | 'none'` - Animación del placeholder (default: `'wave'`).

---

## Usage

```html
<dcx-ng-skeleton></dcx-ng-skeleton>

<dcx-ng-skeleton width="10rem" height="4rem"></dcx-ng-skeleton>

<dcx-ng-skeleton shape="circle" size="3rem"></dcx-ng-skeleton>

<dcx-ng-skeleton animation="none"></dcx-ng-skeleton>
```

## Accessibility

El componente expone `aria-hidden="true"` porque es decorativo y no interactivo — cada
`dcx-ng-skeleton` individual no debe leerse.

Cuando varios skeletons representan una región en carga, `aria-busy="true"` por sí solo
**no garantiza que se anuncie nada** a un lector de pantalla. El contenedor consumidor
debe usar el patrón completo, una sola vez por región (no en cada skeleton):

```html
<div role="status" aria-busy="true">
  <span class="visually-hidden">Cargando…</span>
  <dcx-ng-skeleton shape="circle" size="3rem"></dcx-ng-skeleton>
  <dcx-ng-skeleton width="70%"></dcx-ng-skeleton>
  <!-- … -->
</div>
```

`role="status"` ya implica `aria-live="polite"`, así que no hace falta añadirlo aparte.
El texto oculto (`.visually-hidden`) es lo que el lector de pantalla realmente anuncia —
sin él, `role="status"` no tiene nada que leer. Ver las stories `CardPlaceholder` y
`ListPlaceholder` para ejemplos completos de este patrón.
