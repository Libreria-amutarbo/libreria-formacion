# Tooltip

`dcx-ng-tooltip` muestra información contextual breve al pasar el ratón o al enfocar por teclado el elemento que envuelve. Implementa el patrón WAI-ARIA APG de Tooltip: se activa con `mouseenter`/`focusin`, se cierra con `mouseleave`/`focusout`/`Escape`, y su contenido nunca es interactivo (los enlaces, botones y campos se eliminan automáticamente si se incluyen en `contentHtml`).

El bocadillo se renderiza mediante CDK Overlay (portal a `document.body`), por lo que no queda recortado por ancestros con `overflow: hidden` (diálogos, tarjetas, tablas con scroll…).

---

## Funcionalidad

- **Content Projection**: el elemento envuelto (botón, icono, texto…) se proyecta vía `<ng-content>`.
- **Posicionamiento flexible**: cuatro posiciones (`top`/`bottom`/`left`/`right`) con reubicación automática si no cabe en la posición preferida.
- **Ocultar al hacer clic**: opción `hideTooltipOnClick` para cerrar el tooltip al hacer clic dentro del elemento envuelto.
- **Variantes visuales**: `default` (fondo oscuro) y `primary` (fondo azul, según el mock de diseño).

## Con contenido formateado

`contentHtml` admite formato básico (`<p>`, `<strong>`, `<em>`, `<b>`, `<i>`). Los elementos interactivos (`<a>`, `<button>`, `<input>`, `<select>`, `<textarea>`) se eliminan automáticamente, conservando su texto — un tooltip nunca debe requerir interacción con su contenido.

## Accesibilidad

- `role="tooltip"` con un `id` único por instancia.
- El primer elemento proyectado recibe automáticamente `aria-describedby` apuntando al `id` del tooltip.
- Se activa con `mouseenter` **y** `focusin` — accesible también por teclado, no solo con ratón.
- Se cierra con `mouseleave`, `focusout` **y** la tecla `Escape`.
- El contenido nunca incluye elementos interactivos (se sanea automáticamente).

## Ejemplo de uso

```html
<dcx-ng-tooltip
  content="Este es mi tooltip"
  position="top"
  [hideTooltipOnClick]="false"
>
  <button>Botón</button>
</dcx-ng-tooltip>
```

### Con contenido HTML formateado

```html
<dcx-ng-tooltip
  contentHtml="<p><strong>Importante:</strong> revisa <em>todos</em> los campos</p>"
  position="top"
>
  <dcx-ng-icon name="info-circle"></dcx-ng-icon>
</dcx-ng-tooltip>
```
