# Button

`dcx-ng-button` es el componente de botón base de la librería. Soporta múltiples variantes, tamaños, estados, iconos y el tipo nativo de formulario HTML.

---

## Uso básico

```html
<dcx-ng-button label="Guardar" variant="primary" size="m"></dcx-ng-button>
```

<Canvas of={ButtonClassBasedStories.Default} />

---

## Variantes

| Variante    | Uso recomendado                          |
|-------------|------------------------------------------|
| `primary`   | Acción principal de la pantalla          |
| `secondary` | Acción secundaria o alternativa          |
| `terciary`  | Acción de bajo énfasis (ghost)           |
| `danger`    | Acciones destructivas o de alerta        |
| `text`      | Acción inline sin fondo ni borde         |
| `icon-only` | Botón solo con icono; requiere `ariaLabel` |

## Estados (primary)

`hover`, `pressed`, `focused` son inputs booleanos para forzar un estado visual estático (útil en Storybook y tests visuales). El estado `disabled` usa el atributo nativo `[disabled]`.

<Canvas of={ButtonClassBasedStories.StatesPrimary} />

---

## Con iconos

Usa `icon`, `iconName` (Bootstrap Icons), `iconPosition` (`left` | `right` | `top` | `bottom`) e `iconSize`.

Para añadir un icono adicional a la derecha usa `iconRightName`.

```html
<dcx-ng-button
  label="Guardar"
  variant="primary"
  icon
  iconName="save"
  iconPosition="left"
  iconSize="m">
</dcx-ng-button>
```

<Canvas of={ButtonClassBasedStories.WithIcons} />

---

## Solo icono (accesible)

Cuando no hay `label`, es obligatorio usar `ariaLabel` para proporcionar un nombre accesible al botón.

```html
<dcx-ng-button
  ariaLabel="Guardar"
  variant="icon-only"
  icon
  iconName="save"
  size="m">
</dcx-ng-button>
```

## Output

El componente emite `buttonClick: OutputEmitterRef<{ clicked: boolean }>` en lugar del evento nativo `click`. Esto permite distinguir entre clics de usuario y eventos sintéticos en tests.

```html
<dcx-ng-button label="Acción" (buttonClick)="onAction($event)"></dcx-ng-button>
```
