# Select

The `dcx-ng-select` component is a customizable and accessible dropdown field.
It implements `ControlValueAccessor` to integrate smoothly with Angular Reactive Forms and Template-Driven Forms.

---

## Class-Based Version

This version includes minimal styling using CSS custom properties.
It supports focus styles, keyboard navigation, and optional placeholder behavior.

### Available Properties

- **options**: An array of `{ value: any; label: string }` objects used to populate the dropdown
- **placeholder**: Optional placeholder text shown when no value is selected
- **label**: Visible label text rendered above the select
- **ariaLabel**: Accessible name used **only when no visible label is provided**

---

## Keyboard Navigation

The select follows the WAI-ARIA APG combobox pattern (`aria-activedescendant`) — focus never
leaves the control (or the search input, when `searchable`), only a visual/AT highlight moves:

- **Tab** to focus the control
- **Arrow Down / Arrow Up** — opens the panel if closed; when open, moves the highlighted
  option (`aria-activedescendant`) without changing the selected value
- **Home / End** — jump the highlight to the first / last enabled option
- **Enter** — confirms the highlighted option as the selected value and closes the panel
- **Escape** — closes the panel and returns focus to the control
- Clicking outside the component also closes the panel

---

## Usage in Reactive Forms

This example shows how to use the select within a reactive form.

```html
<form [formGroup]="form">
  <!-- With visible label (recommended) -->
  <dcx-ng-select
    formControlName="basic"
    [options]="selectOptions"
    placeholder="Choose an option"
    label="Select an option">
  </dcx-ng-select>

  <!-- No visible label (use ariaLabel for accessibility) -->
  <dcx-ng-select
    formControlName="basicNoLabel"
    [options]="selectOptions"
    placeholder="Choose an option"
    ariaLabel="Select an option">
  </dcx-ng-select>
</form>
```
