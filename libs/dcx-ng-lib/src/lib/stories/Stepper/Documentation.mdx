# Stepper

`dcx-ng-stepper` guía al usuario por una secuencia de pasos, con navegación lineal
(secuencial) o libre, orientación horizontal o vertical, y estados de progreso
(activo, completado, error, deshabilitado, opcional).

Ideal para formularios multi-paso, asistentes de configuración y flujos de proceso.

---

## Uso básico

```html
<dcx-ng-stepper
  [steps]="steps"
  [activeStepId]="'1'"
  [orientation]="'horizontal'"
  [linear]="false"
  (stepChange)="onStepChange($event)"
></dcx-ng-stepper>
```

```typescript
const steps = [
  { id: '1', label: 'Datos personales', description: 'Introduce tus datos' },
  { id: '2', label: 'Dirección', description: 'Confirma tu dirección' },
  { id: '3', label: 'Revisión', description: 'Revisa tu información' },
];
```

## Propiedades

| Propiedad | Tipo | Default | Descripción |
|---|---|---|---|
| `steps` | `DcxStepperItem[]` | requerido | Array de pasos |
| `activeStepId` | `string \| number` | `''` | ID del paso activo (por defecto, el primero habilitado) |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientación |
| `linear` | `boolean` | `false` | Solo permite navegación secuencial |
| `showStepNumbers` | `boolean` | `true` | Muestra los números de paso |
| `size` | `'s' \| 'm' \| 'l' \| 'xl'` | `'m'` | Tamaño del componente |
| `ariaLabel` | `string \| null` | `null` | Nombre accesible del landmark de navegación |

## Eventos

| Evento | Tipo | Descripción |
|---|---|---|
| `stepChange` | `DcxStepperChangeEvent` | Se emite cuando cambia el paso activo |
| `stepClick` | `DcxStepperItem` | Se emite al hacer click en un paso |

## Interfaz `DcxStepperItem`

```typescript
interface DcxStepperItem {
  id: string | number;
  label: string;
  description?: string;
  disabled?: boolean;
  completed?: boolean;
  error?: boolean;
  optional?: boolean;
  icon?: string;
  contentTpl?: TemplateRef<unknown>;
}
```

## Interfaz `DcxStepperChangeEvent`

```typescript
interface DcxStepperChangeEvent {
  previousStepId: string | number | null;
  currentStepId: string | number;
  previousIndex: number;
  currentIndex: number;
}
```

## Estados

- **Activo**: el paso actualmente visible — borde y texto en color primario.
- **Completado**: un paso ya finalizado — indicador relleno con marca de check.
- **Error**: un paso con errores de validación — borde y texto en rojo.
- **Deshabilitado**: un paso con el que no se puede interactuar — colores atenuados.
- **Opcional**: se añade la etiqueta "(opcional)" bajo la descripción del paso.

---

## Accesibilidad

- El contenedor raíz es un `<nav>` con `aria-label` configurable (`ariaLabel`).
- Los pasos se renderizan dentro de un `<ol role="list">` — el orden es información
  real, no solo visual.
- El paso activo se marca con `aria-current="step"`.
- Los estados "completado"/"error" incluyen texto oculto para lectores de pantalla
  ("Completado"/"Error"), ya que sus iconos son decorativos (`aria-hidden`).
- **Teclado**: flechas para navegar entre pasos habilitados (horizontal:
  izquierda/derecha, vertical: arriba/abajo), `Home`/`End` para saltar al primer/último
  paso habilitado, `Enter`/`Espacio` para activar el paso con foco. El foco usa un
  patrón de *roving tabindex*: solo el paso activo es alcanzable con Tab.

## Clases CSS

- `.dcx-stepper`: contenedor raíz
- `.dcx-stepper--horizontal` / `.dcx-stepper--vertical`: orientación
- `.dcx-stepper--s|m|l|xl`: tamaño
- `.dcx-stepper__step`: botón de cada paso
- `.dcx-stepper__step--active` / `--completed` / `--error` / `--disabled`: estados
- `.dcx-stepper__content`: contenedor del contenido del paso activo

## Theming

El componente usa custom properties CSS para el color:

- `--bg-primary`: color primario (paso activo/completado, conector de progreso)
- `--border-light`: color de borde por defecto
- `--text-dark`: color de texto principal
- `--text-muted`: color de texto secundario
- `--color-error`: color del estado de error
