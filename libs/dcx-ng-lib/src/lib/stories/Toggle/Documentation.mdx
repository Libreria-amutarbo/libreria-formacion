# Toggle

`dcx-ng-toggle` es un switch accesible para representar estados on/off. Implementa el patrón ARIA de switch sobre un `<button role="switch">` nativo, con foco, `disabled` y activación por teclado (Enter/Espacio) gratis del navegador.

---

## Versión Class Based

Incluye estilos visuales por defecto basados en clases BEM. El color activo sigue los tokens de diseño y no es configurable mediante propiedades del componente.

### Propiedades disponibles

- **checked**: si el toggle está en estado "on".
- **disabled**: deshabilita la interacción si es `true`.
- **label**: texto de la etiqueta mostrado junto al toggle.
- **ariaLabel**: nombre accesible explícito. Si no se indica, se usa `label` como alternativa antes de caer en el genérico "Toggle".
- **size**: `'s' | 'm' | 'l' | 'xl' | 'auto'` — controla el tamaño del toggle (por defecto `'m'`).
- **textPosition**: `'top' | 'bottom' | 'left' | 'right'` — posición del label respecto al control (por defecto `'right'`).
- **(toggled)**: evento emitido con el nuevo valor de `checked` cada vez que el toggle cambia (clic o teclado).

## Ejemplo de uso

```html
<dcx-ng-toggle
  [checked]="featureEnabled"
  label="Activar función"
  size="m"
  (toggled)="handleToggle($event)"
></dcx-ng-toggle>
```

```typescript
handleToggle(value: boolean) {
  this.featureEnabled = value;
}
```

### Con formularios reactivos

El componente implementa `ControlValueAccessor`, por lo que también funciona con `formControlName`/`[formControl]`:

```html
<form [formGroup]="form">
  <dcx-ng-toggle formControlName="darkMode" label="Modo oscuro"></dcx-ng-toggle>
</form>
```

---

## Accesibilidad

- `role="switch"` + `aria-checked` sobre un `<button>` nativo.
- Nombre accesible: `ariaLabel` explícito → `label` visible → `"Toggle"` como último recurso. Si ocultas el label visual, indica siempre `ariaLabel`.
- `disabled` nativo — se elimina automáticamente del orden de tabulación.
- Foco visible vía `:focus-visible`, sin anillo en clics de ratón.
