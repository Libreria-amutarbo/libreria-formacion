# Message

El componente `dcx-web-message` muestra mensajes informativos, de éxito, advertencia o error manteniendo accesibilidad WCAG AA y consistencia visual con el Design System DCX.

---

## Cuándo usarlo

- Confirmaciones de acciones
- Errores de sistema
- Mensajes de validación
- Información contextual
- Alertas importantes
- Confirmaciones de guardado

---

## Variantes soportadas

```html
notification
success
warning
error
