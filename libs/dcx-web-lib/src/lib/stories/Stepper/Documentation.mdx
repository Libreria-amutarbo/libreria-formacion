# Stepper

`dcx-web-stepper` guía al usuario por una secuencia de pasos, con navegación lineal o libre, orientación horizontal o vertical y distintos estados de progreso.

Es ideal para:

- Formularios multipaso
- Procesos de compra
- Wizards
- Asistentes de configuración
- Flujos de onboarding

---

## Uso básico

```html
<dcx-web-stepper
  .steps=${steps}
  activeStepId="1"
  orientation="horizontal"
>
</dcx-web-stepper>
```

```ts
const steps = [
  {
    id: '1',
    label: 'Datos personales',
    description: 'Introduce tus datos',
  },
  {
    id: '2',
    label: 'Dirección',
    description: 'Confirma tu dirección',
  },
  {
    id: '3',
    label: 'Revisión',
    description: 'Revisa tu información',
  },
];
```

## Con contenido por paso

Angular utilizaba `TemplateRef` mediante la propiedad `contentTpl`.

En Web Components el contenido personalizado se proporciona mediante el slot `step-content`.

```html
<dcx-web-stepper>
  <div slot="step-content">
    Contenido personalizado
  </div>
</dcx-web-stepper>
```

## API

| Propiedad | Tipo | Default | Descripción |
|------------|------|----------|-------------|
| `steps` | `DcxStepperItem[]` | `[]` | Lista de pasos |
| `activeStepId` | `string \| number` | `''` | Paso actualmente activo |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientación del componente |
| `linear` | `boolean` | `false` | Navegación secuencial |
| `showStepNumbers` | `boolean` | `true` | Muestra numeración de los pasos |
| `size` | `'s' \| 'm' \| 'l' \| 'xl'` | `'m'` | Tamaño visual |
| `ariaLabel` | `string \| null` | `null` | Nombre accesible del landmark |

---

## Eventos

| Evento | Detail | Descripción |
|----------|----------|----------|
| `stepClick` | `DcxStepperItem` | Emitido al hacer click sobre un paso |
| `stepChange` | `DcxStepperChangeEvent` | Emitido cuando cambia el paso activo |

## Slots

### step-content

Permite renderizar contenido personalizado debajo del paso activo.

```html
<dcx-web-stepper>
  <div slot="step-content">
    Mi contenido personalizado
  </div>
</dcx-web-stepper>
```
