# Tabs

`dcx-web-tabs` permite navegar entre diferentes áreas de contenido siguiendo el patrón ARIA de Tabs (`tablist` / `tab` / `tabpanel`) con soporte para navegación mediante teclado, variantes visuales, badges, iconos, scroll horizontal y contenido proyectado.

---

## Cuándo usarlo

- Navegación entre secciones
- Agrupación de contenido relacionado
- Pantallas multipaso
- Área de configuración
- Dashboards
- Gestión de módulos
- Navegación secundaria

---

## API

| Propiedad | Tipo | Default | Descripción |
|------------|------------|------------|------------|
| tabs | DcxTabItem[] | [] | Colección de pestañas |
| activeTabId | string | '' | Pestaña activa |
| variant | line \| pill \| brand \| subtle | line | Variante visual |
| hasControls | boolean | false | Controles numerados |
| ariaLabel | string \| null | null | Nombre accesible del tablist |

---

## Eventos

| Evento | Detail | Descripción |
|----------|----------|----------|
| tabChange | string | Identificador de la pestaña seleccionada |
