# Drawer

`dcx-web-drawer` es un panel deslizante lateral, superior o inferior con comportamiento modal opcional, adaptado al diseño de la librería.

- Control de visibilidad mediante la propiedad `.open`.
- Soporte para posiciones: `left`, `right`, `top`, `bottom`.
- Modo modal opcional con máscara (`modal`) y cierre por click en la máscara (`dismissible`).
- Cierre al pulsar la tecla `Escape` usando `closeOnEscape`.
- Header con título y botón de cierre opcionales.
- Slots para personalización completa: `drawerHeader` y `drawerFooter`.
- Estilos basados en CSS Custom Properties de la librería.

> **Nota de scroll:** por defecto los ejemplos usan `blockScroll=false` para permitir el desplazamiento de la página de Docs. Revisa el ejemplo **BlockScrollTrue** para ver el bloqueo intencional de la página.

---

## Uso básico

```html
<dcx-web-drawer header="Título del Drawer" open="false" position="right">
  <p>Contenido del drawer...</p>
</dcx-web-drawer>
```

## Header Personalizado (Slot)

Permite proyectar el slot `drawerHeader` para reemplazar el texto plano por un contenido HTML complejo.

```html
<dcx-web-drawer open="true">
  <div slot="drawerHeader">
    <h3>Header Custom</h3>
  </div>
  <p>Contenido...</p>
</dcx-web-drawer>
```

<Canvas of={DrawerStories.WithCustomHeader} />

---

## Footer Personalizado (Slot)

Permite proyectar el slot `drawerFooter` para añadir botones de acción en la parte inferior.

```html
<dcx-web-drawer open="true">
  <p>Contenido...</p>
  <div slot="drawerFooter">
    <dcx-web-button label="Guardar"></dcx-web-button>
  </div>
</dcx-web-drawer>
```
