# Checkbox

El componente `dcx-web-checkbox` permite seleccionar valores en tres estados:

- ✅ Marcado (`true`)
- ➖ Indeterminado (`false`)
- ⬜ Sin valor (`null`)

Equivalente funcional al componente Angular, pero implementado como Web Component.
