# Checkbox

El componente `dcx-web-checkbox` permite seleccionar valores con **tres estados**:

- ✅ Marcado (`true`)
- ➖ Indeterminado (`false`)
- ⬜ Sin valor (`null`)

Este componente está desarrollado como **Web Component (Lit)**, proporcionando encapsulación, reactividad y compatibilidad con cualquier framework.

---

## Versión Class-Based

La versión class-based utiliza estilos CSS y API basada en propiedades para máxima flexibilidad.

## Personalización

Puedes personalizar:

- **label** → texto del checkbox  
- **value** → estado (`true | false | null`)  
- **disabled** → deshabilita interacción  
- **error** → muestra estado de error  
- **errorMessage** → mensaje debajo  
- **required** → añade indicador visual  
- **labelPosition** → `'left' | 'right'`

## Evento

| Evento | Descripción |
|------|------------|
| `changeOptions` | Se emite al cambiar el estado |

```ts
element.addEventListener('changeOptions', (e) => {
  console.log(e.detail); // nuevo estado
});
``
