# Skeleton

`dcx-web-skeleton` muestra un placeholder decorativo mientras el contenido real se encuentra cargando.

Está inspirado en PrimeNG Skeleton y mantiene una API simple para definir forma, dimensiones y animación.

## API

| Propiedad | Tipo | Default | Descripción |
|------------|------------|------------|------------|
| shape | 'rectangle' \| 'circle' | rectangle | Forma visual |
| width | string | 100% | Ancho CSS |
| height | string | 1rem | Alto CSS |
| size | string \| null | null | Tamaño único para ancho y alto |
| borderRadius | string \| null | null | Radio CSS para rectángulos |
| animation | 'wave' \| 'none' | wave | Animación visual |
