# Spinner

`dcx-web-spinner` es un indicador de carga circular accesible y personalizable.

Puede utilizarse:

- de forma independiente
- con título y descripción
- con retraso configurable
- como overlay mediante `wrapper`
- con contenido proyectado mediante slot
