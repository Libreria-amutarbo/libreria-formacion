# Dialog

`dcx-web-dialog` es un componente modal accesible implementado como Web Component.

- Se abre estableciendo la propiedad `.visible`.
- Se cierra escuchando el evento `closeDialog`.
- El contenido se proyecta mediante slots: `slot="body"` y `slot="footer"`.
- Soporta posicionamiento configurable, backdrop opcional, header con título y botón de cierre.

---

DcxWebDialog es un diálogo modal:

- Proporciona un `dialogId` al componente para generar identificadores accesibles.

- El contenido se pasa por slots (`slot="body"`, `slot="footer"`).

## API

| Atributo / Propiedad | Tipo | Default | Descripción |
|----------------------|------|---------|-------------|
| `dialogId` | `string \| undefined` | `undefined` | Identificador del diálogo. Se usa para generar ids accesibles |
| `title` | `string` | `''` | Título del diálogo. Si está vacío, no se renderiza el título |
| `visible` | `boolean` | `false` | Controla si el diálogo está abierto |
| `showClose` | `boolean` | `true` | Muestra u oculta el botón de cierre |
| `position` | `DialogPosition` | `'center'` | Posición del diálogo en pantalla |
| `closeOnBackdrop` | `boolean` | `true` | Permite cerrar al hacer clic en el backdrop |

---

## Eventos

| Evento | Tipo | Descripción |
|--------|------|-------------|
| `closeDialog` | `CustomEvent<void>` | Se emite cuando el diálogo solicita cerrarse |

---

## Slots

| Slot | Descripción |
|------|-------------|
| `body` | Contenido principal del diálogo |
| `footer` | Acciones del diálogo |

---

## Accesibilidad

`dcx-web-dialog` incluye:

- `role="dialog"`
- `aria-modal="true"`
- `aria-labelledby` cuando existe título
- cierre mediante tecla `Escape`
- cierre opcional mediante backdrop
- botón de cierre con `aria-label="Cerrar diálogo"`
