# Progressbar

El componente `dcx-web-progressbar` es un indicador visual para mostrar el progreso de una tarea o guiar al usuario a través de un proceso de múltiples pasos.

---

## Características

### 🎯 Tres Variantes

- **Default**: barra de progreso simple
- **Segmented**: barra dividida en segmentos con animación
- **Stepper**: proceso por pasos numerados o completados

### 📊 Opciones de Visualización

- Tooltip de porcentaje
- Cabecera con porcentaje
- Checkmarks para pasos completados
- Segmentación configurable

### 🎨 Diseño

- Basado en Capgemini Design Tokens
- Responsive
- Accesible
- Compatible con WCAG AA

---

## API

### Propiedades

| Propiedad | Tipo | Default | Descripción |
|------------|------------|------------|------------|
| variant | `'default' \| 'segmented' \| 'stepper'` | `'default'` | Variante visual |
| value | number | `0` | Valor de progreso entre 0 y 100 |
| label | string | `''` | Etiqueta de cabecera |
| ariaLabel | string | `''` | Nombre accesible |
| showLabel | boolean | `false` | Muestra cabecera |
| showTooltip | boolean | `false` | Muestra tooltip |
| steps | DcxProgressStep[] | `[]` | Pasos del stepper |
| currentStep | number | `0` | Paso activo |
| showCheckmarks | boolean | `false` | Checks en completados |
| segments | number | `5` | Número de segmentos |
