# Toggle

`dcx-web-toggle` es un switch accesible construido con Web Components y Lit para representar estados binarios (on/off).

Implementa el patrón ARIA recomendado mediante un botón nativo con:

- role="switch"
- aria-checked
- aria-label
- disabled nativo

preservando compatibilidad WCAG AA.

---

## Versión Class Based

El componente utiliza estilos internos basados en BEM y los tokens definidos en `capgemini-tokens.css`.

## API

| Atributo / Propiedad | Tipo | Default | Descripción |
|----------------------|------|---------|-------------|
| checked | boolean | false | Estado actual del toggle |
| disabled | boolean | false | Deshabilita la interacción |
| label | string \| null | null | Texto visible |
| ariaLabel | string \| null | null | Nombre accesible explícito |
| size | s \| m \| l \| xl | m | Tamaño visual |
| textPosition | top \| bottom \| left \| right | right | Posición del texto |

---

## Eventos

| Evento | Detail | Descripción |
|----------|----------|----------|
| toggled | boolean | Nuevo estado tras una interacción |
