Editor

Editor de texto enriquecido con barra de herramientas de formato (negrita, cursiva, subrayado, listas y limpiar formato). Implementa ControlValueAccessor para integración con Angular Forms.

01 Default
02 Con valor inicial
03 Solo lectura

La toolbar y el área editable quedan desactivadas. El contenido es visible pero no editable.

04 Disabled

El editor y todos los botones de la toolbar quedan deshabilitados con opacidad reducida.

05 Inválido
06 Toolbar personalizada

El input toolbarActions limita las acciones visibles a solo formato básico de texto.

07 Sin label visible

Cuando el diseño no incluye una etiqueta visible, usa ariaLabel para proporcionar el nombre accesible a lectores de pantalla.
