Components

Message

Mensaje en línea con cuatro severidades (notification, success, warning, error), icono por severidad, título, enlace y botón de cierre. Anuncia su contenido a lectores de pantalla mediante `role`/`aria-live`.

01 Default
02 Notification
03 Success
04 Warning
05 Error
06 With Link
07 Closable

El botón de cerrar oculta el mensaje y emite el evento `closed`.
