Input OTP

Componente para introducir códigos de verificación en varias casillas, con soporte para navegación por teclado, modo numérico, enmascarado e integración con formularios Angular.

03 Masked

Oculta cada carácter introducido manteniendo el valor real disponible.

04 Interactive

Muestra el valor actual, el último código completado y permite limpiar el estado.
